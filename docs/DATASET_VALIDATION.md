## 3. Strict Anti-Fabrication Rule Enforcement
In accordance with mandatory anti-fabrication guidelines:
1. **No Synthetic Substitution:** Synthetic imagery generated by `simulator/generator.py` is reserved exclusively for algorithmic unit testing and pipeline integration tests. It is never presented as real acoustic data or used to fake dataset validation.
2. **No Arbitrary Internet Scraping:** No random optical underwater photographs or unrelated optical object detection datasets (e.g. COCO optical objects) have been substituted. Sidescan sonar operates via acoustic acoustic backscatter and shadow geometry, which are fundamentally incompatible with optical camera datasets.

---

## 4. Required Survey-Level Splitting Protocol (For Dataset Ingestion)
When a legitimate Sidescan Sonar dataset is supplied:
- **Zero Spatial Leakage:** Do not split randomly by image tiles.
- **Survey-Level Split:** Entire continuous survey tracks must be partitioned into `train`, `val`, and `test` to ensure cross-validation independence:
  - Survey Tracks A & B $\rightarrow$ `train/` (70%)
  - Survey Track C $\rightarrow$ `val/` (15%)
  - Survey Track D $\rightarrow$ `test/` (15%)
